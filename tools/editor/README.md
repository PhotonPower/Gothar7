# Welt-Editor (Grundlage M4)

Spacer-artiger Editor, umgesetzt als **Editor-Modus der Engine** (ImGui-Overlay im
selben Prozess), damit Editor und Spiel immer dieselbe Darstellung haben.

- Grundlage (Vob-Platzierung, eigene Gizmos, Speichern): **M4, umgesetzt** – `gothar --editor`
- Wegnetz-, Trigger-, Licht- und Zonen-Editor: **M16**

Spezifikation: `docs/modules/tools.md`
