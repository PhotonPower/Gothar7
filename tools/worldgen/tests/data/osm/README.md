# Testdaten: OSM-Ausschnitt Leonberger Marktplatz

`leonberg_marktplatz.osm.pbf`: alle Knoten und Wege mit `highway`, `barrier`, `place`, `amenity`,
`natural` oder `historic`, die das Rechteck ±130 m (Ost-West) × ±70 m (Nord-Süd) um den
Marktbrunnen (E 501115, N 5405347, EPSG:25832) berühren, samt aller referenzierten Knoten.
Enthält u. a. den Marktplatz (`place=square`), den Marktbrunnen und einen Abschnitt der Stadtmauer.
