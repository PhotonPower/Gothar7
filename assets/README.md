# Assets

**Wichtig:** In dieses Repository gehoeren **ausschliesslich eigene oder frei lizenzierte
Assets**. Original-Dateien aus Gothic 1 (Modelle, Texturen, Sounds, Musik, Sprachausgabe,
Skripte, Welten) sind urheberrechtlich geschuetzt und duerfen **nicht** eingecheckt oder
mit dem Spiel ausgeliefert werden.

```
assets/
  source/     Quelldateien (glTF/.glb, PNG, OGG, .blend) – versioniert (spaeter ggf. Git LFS)
  cooked/     Ausgabe von g7-cook (Laufzeitformate, .g7pak) – NICHT versioniert
  LICENSES.md Herkunft und Lizenz jedes Fremd-Assets (Pflicht ab dem ersten Fremd-Asset)
```

Siehe `docs/06-asset-pipeline.md`.
